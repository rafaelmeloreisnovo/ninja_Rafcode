## Intake rule

For every future external component record:

- exact source locator;
- author/rightsholder;
- SPDX identifier when available;
- exact license text/version;
- attribution/NOTICE requirements;
- modification notice requirements;
- patent/trademark conditions where material;
- compatibility decision;
- evidence/ref.

Unrecognized license name -> `TOKEN_VAZIO` -> no incorporation.

`ATTRIBUTION != PERMISSION`  
`PUBLIC != PUBLIC_DOMAIN`  
`REPOSITORY_OWNER != AUTHOR`
